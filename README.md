# ShopProject — учебный интернет-магазин

Контрольная работа №1 по дисциплине «Фронтенд и бэкенд разработка».

Проект представляет собой адаптивный многостраничный сайт интернет-магазина компьютерных аксессуаров. В нём реализованы каталог, карточка товара, форма заказа, контактная страница, модальное окно и клиентская валидация.

## Структура

- `index.html` — главная страница;
- `catalog.html` — каталог товаров и фильтры;
- `product.html` — карточка товара и таблица характеристик;
- `order.html` — форма оформления заказа;
- `contacts.html` — контакты и режим работы;
- `css/style.css` — общие адаптивные стили;
- `js/main.js` — модальное окно и валидация форм;
- `images/` — иллюстрации товаров.

## Технологии

HTML5, CSS3, Flexbox, CSS Grid, БЭМ, JavaScript, Git и GitHub Pages.

## Реализовано

- семантическая HTML-разметка и единая навигация;
- уникальные заголовки и описания страниц;
- адаптивные сетки каталога и карточек;
- CSS-переменные, состояния `hover`, `focus-visible` и `disabled`;
- относительное, абсолютное, липкое и фиксированное позиционирование;
- хлебные крошки, бейджи, фильтры и кнопка возврата наверх;
- таблица технических характеристик;
- отдельная форма заказа и модальное окно быстрой заявки;
- HTML- и JavaScript-валидация с сообщениями об успешной отправке;
- автоматический выбор товара при переходе из каталога.
