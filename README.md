# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — подробная страница товара;
- `order.html` — форма оформления заказа;
- `contacts.html` — контактная информация;
- `css/style.css` — общий файл стилей;
- `js/main.js` — открытие модального окна и обработка формы;
- `images/` — изображения проекта;
- `.gitignore` — исключения Git;
- `README.md` — описание проекта.

## Используемые технологии

- HTML5;
- CSS3;
- JavaScript;
- Flexbox;
- CSS Grid;
- БЭМ;
- Git;
- GitHub;
- GitHub Pages.

## Как запустить проект

1. Скачать или клонировать репозиторий.
2. Открыть папку проекта в Visual Studio Code.
3. Открыть `index.html` в браузере или запустить через Live Server.
