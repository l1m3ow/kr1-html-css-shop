# ShopProject — учебный интернет-магазин

Контрольная работа №1 по дисциплине «Фронтенд и бэкенд разработка».
Практические занятия №5–8: многостраничность, Flexbox/Grid, БЭМ и итоговая проверка.

## Описание

ShopProject — многостраничный HTML/CSS-сайт каталога компьютерных аксессуаров.
Пять страниц связаны единым меню. В проекте есть карточки, таблица характеристик,
отдельная форма заявки и нативное модальное окно. JavaScript проверяет демо-формы
и выбирает товар в форме по параметру URL. Bootstrap и другие CSS-фреймворки не используются.

## Структура

- `index.html` — главная: первый экран, преимущества, популярные товары и быстрая заявка;
- `catalog.html` — шесть товаров и статический интерфейс фильтров;
- `product.html` — описание клавиатуры и таблица характеристик;
- `order.html` — отдельная демо-форма с выбором товара;
- `contacts.html` — демонстрационные контакты и согласованный график;
- `css/style.css` — общие стили, CSS-переменные, Flexbox/Grid и медиазапросы;
- `js/main.js` — модальное окно, клиентская проверка и сброс состояния форм;
- `images/` — локальные SVG-иллюстрации товаров;
- `docs/WORKS_05_08.md` — разбор изменений, проверки и 74 ответа на вопросы;
- `.gitignore` — исключения служебных файлов из Git.

## Запуск

Откройте `index.html` в браузере либо откройте папку в VS Code и запустите Live Server.
Установка зависимостей и сборка не нужны.

Опубликованная версия: https://l1m3ow.github.io/kr1-html-css-shop/

## Практическое занятие №5

- Пять страниц имеют единое основное меню, уникальные `title` и `meta description`.
- На внутренних страницах есть хлебные крошки с обозначением текущей страницы.
- Подвалы всех страниц содержат переходы `index.html#advantages`, `index.html#popular`
  и `index.html#contacts`.
- Цели якорей выделяются через `:target`, `scroll-margin-top` оставляет место под шапкой.

## Практическое занятие №6

- Меню и группы действий используют Flexbox.
- Карточки товаров образуют Grid-сетку; внутри карточки используется Flexbox.
- Каталог имеет именованные области `filters` и `products` через `grid-template-areas` и `grid-area`.
- На экране до 900px карта областей становится вертикальной; до 650px карточки идут в один столбец.

## Практическое занятие №7

- Используются блоки `site-nav`, `product-card`, `order-form`, `order-dialog`, `breadcrumbs`.
- Части компонентов названы через `block__element`, варианты — через `block--modifier`.
- Поля, подписи, действия формы, кнопка окна и ссылки крошек получают собственные классы.
- CSS не стилизует элементы через идентификаторы и не использует inline-стили.
- Идентификаторы сохранены для подписей полей, якорей и JavaScript.

## Практическое занятие №8

- Есть пять обязательных страниц, форма, модальное окно и таблица.
- Показаны `relative`, `absolute`, `sticky`, `fixed` и `z-index`.
- У интерактивных элементов есть видимый фокус.
- Уточнены демонстрационные сообщения, согласованы часы работы.
- Подготовлен список проверок и справочник для объяснения реализации.

## Проверка

1. Откройте все пять страниц и проверьте пункты меню и активный пункт.
2. Из подвала каталога перейдите к преимуществам, товарам и контактам главной.
3. Проверьте каталог на широком и узком экране: фильтры не должны оставаться во второй колонке.
4. На главной нажмите «Заказать» у разных карточек, проверьте открытие окна.
5. Клик по внутренним отступам окна не закрывает форму; крестик, Escape и фон снаружи закрывают.
6. Отправьте пустую форму: появится сообщение браузера и отметка ошибочных полей.
7. Заполните корректно: имя от двух символов, email, телефон `+7 (900) 123-45-67`, тему и согласие.
8. После успеха начните новый ввод или нажмите «Очистить»: старое сообщение исчезает.
9. Откройте `order.html?product=mouse`: выбрана мышь; после сброса товар из ссылки сохраняется.
10. Проверьте неизвестное значение `order.html?product=unknown`: остаётся предложение выбрать товар.
11. Проверьте клавиатурную навигацию Tab, масштаб 200%, Console и Network.

## Ограничения

Это учебный интерфейс. Формы не отправляют данные на сервер, оплата и запись заказов не выполняются.
Фильтры каталога статические, что допускает задание КР №1. Все ссылки «Подробнее» ведут
на одну страницу клавиатуры. Полноценная фильтрация, динамические подробности и backend
не заявляются как реализованные.

## Расширения базового интерфейса

В коде присутствуют локальные SVG-иллюстрации, адаптивные сетки, бейджи товаров,
фиксированная кнопка «Наверх» на всех пяти страницах, автоматический выбор товара из URL и демо-проверка форм.
Для защиты необходимо уметь объяснить эти решения и честно указать собственный вклад.
Само наличие готовых файлов не доказывает самостоятельность выполнения и не гарантирует оценку.

## Цветовая палитра и кнопка возврата

Сайт использует тёплую терракотовую и песочную палитру: кремовый фон, тёмно-коричневый
текст, терракотовые кнопки и золотистые акценты. В той же гамме оформлены SVG-иллюстрации.

На каждой странице есть одна фиксированная ссылка «Наверх» с доступной подписью.
Она ведёт к `body#top`, поэтому возвращает к самому началу страницы, включая шапку.
При запросе уменьшенного движения плавная прокрутка отключается.
Уведомление демо-формы располагается выше стрелки.

Проверка: прокрутите каждую из пяти страниц вниз и нажмите стрелку; повторите на
узком экране и с клавиатуры. Проверьте новую гамму у карточек, форм, таблицы и подвала.
